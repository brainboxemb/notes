Button SHIM reference and mounting

October 27, 2026

A useful starting point for Brainbox Zero is:

  • Taking The Raspberry Pi Inky pHAT To The Next Level

The project combines a Raspberry Pi Zero, an e-paper display and a Button SHIM. That makes it a useful reference for the basic idea of a small Raspberry Pi Zero platform with a display and a few physical buttons.

Based on this idea, a Button SHIM was investigated for Brainbox Zero. Pimoroni had sold out, but two boards were found and bought from PiLover in Italy:

  • Button SHIM - PiLover

The Electromaker build mounts the Button SHIM below the Raspberry Pi Zero using an extra-long header.

Pins used by the Button SHIM

According to the Button SHIM pinout on Pinout.xyz, the SHIM uses these Raspberry Pi header pins:

FunctionRaspberry Pi pin
5 V power4
3.3 V power17
GND6
I2C SDA / GPIO 23
I2C SCL / GPIO 35

The official Pimoroni Button SHIM library uses I2C bus 1 and address 0x3f.

Mounting idea

For Brainbox Zero, the idea is to use a normal 2x20 male Raspberry Pi header rather than the extra-long header used in the Electromaker example.

A normal 2x20 header sold for the Raspberry Pi Zero is for example:

  • 40-pin male header - 2x20 - Kiwi Electronics — specified total pin length: 11.6 mm.

The point of this reference is only the mechanical size of a normal header.

The question to test is whether, after soldering the normal header into the Raspberry Pi Zero, the pins still protrude about 1 mm below the Pi PCB. The Button SHIM PCB is 0.8 mm thick, so that may be enough to slide the SHIM over the remaining pin ends and solder it underneath the Pi.

The actual protruding length still needs to be measured.
