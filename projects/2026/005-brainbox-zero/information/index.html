Brainbox Zero Information

General project information and references for Brainbox Zero.

Platform

Brainbox Zero targets the Raspberry Pi Zero family.

The first validation target is a Raspberry Pi Zero W so that the base image can be checked with Wi-Fi and SSH in addition to normal boot and serial-console behaviour.

Scope

The platform is intended to be generic and reusable.

Application-specific software and event-specific configuration are outside the base-image scope unless they later become explicit reusable platform components.

Device-specific configuration

The base image should not permanently contain secrets or per-device identity.

Examples of device-specific configuration include:

  • hostname;
  • Wi-Fi credentials;
  • user configuration;
  • SSH keys.

These belong to the device setup process rather than the reusable image itself.
