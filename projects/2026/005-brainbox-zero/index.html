Brainbox Zero

● Active · 🔍 Orientation · Started 2026-10-27 · Updated 2026-10-29

Current: Setting up the first Raspberry Pi Zero hardware and software platform.

Raspberry Pi, Raspberry Pi OS, Linux, Embedded

Brainbox Zero is a practical Raspberry Pi Zero based platform with a display, a few buttons and the software needed to use them.

Goal

Build a useful Raspberry Pi Zero platform consisting of:

  • a Raspberry Pi Zero;
  • a small display;
  • a few physical buttons;
  • the required software.

Part of the project is also to investigate practical options for firmware/software updates.

Current focus

Current work includes:

  • setting up the first Raspberry Pi OS Lite image;
  • working out the Button SHIM connection and mounting;
  • bringing the hardware and software together into a usable base platform.

Roadmap

  • get the basic Raspberry Pi Zero platform working;
  • add the display and buttons;
  • add the required software;
  • investigate options for updating the software/firmware.

Structure

Project work is currently organised into:

  • Log for chronological progress;
  • Information for project scope, hardware and references.
