Simple MFT

● Active · 🔍 Orientation · Started 2026-11-16 · Updated 2026-11-17

Woodworking MFT Circular Saw Workbench

Current: Worktop, detailed GuideRail profiles and the first 800 mm MFT assembly are in CAD; rail dogs/support and fence design are next.

Simple MFT is a small woodworking project for a simple, compact MFT-style cutting setup. The main goal is not to reproduce a full Festool-style MFT table, but to create a practical surface for making repeatable cuts with a circular saw and guide rail.

Goal

Create a setup that is:

  • simple to build and use;
  • suitable for cutting sheet and board material with a circular saw;
  • compact enough to store or move easily;
  • useful with standard MFT-style workholding where that helps;
  • able to support a simple fence or stop system for repeatable cuts.

Current design status

The current Simple MFT model still contains only the perforated worktop, without a supporting box or frame. The project uses the Craftmaker S30 replacement MDF top as a visual and dimensional reference, but the precise positions of holes and diagonal clamping slots have not been verified. A reusable guide rail component exists separately in the CAD repository with detailed Festool and Makita profile variants. The first assembly now places a 800 mm Festool-profile rail over the worktop; rail dogs/support hardware and a possible VIDGA-based fence remain to be worked out.

The SCPF implementation is still being developed and tested. The illustration on this page is a conceptual drawing, not a photograph of the product or a verified CAD render.

Main inspiration

The starting point is Techydiy’s Mini Portable Workbench, a lightweight torsion-box bench with an MFT-style top:

  • Techydiy project page with build details

The reference design uses a rigid lightweight construction, 20 mm dog holes and a 96 mm MFT-style grid. For this project the interesting part is mainly the small portable work surface and workholding concept; the final construction may be simpler.

Candidate parts and ideas

See also MFT inserts for 20 mm dog-hole accessories such as passive tension-fit bench dogs.

Perforated worktop

A possible shortcut is a ready-made perforated MDF worktop rather than drilling a complete MFT grid from scratch:

The nominal product dimensions discussed for the CAD concept are 805 × 555 × 18 mm, with 20 mm dog holes. Confirm the current seller specifications and measure the actual hole spacing, slot positions and edge clearances before relying on the board for accurate cuts.

Rail dogs and guide rail

The preferred idea is to position the guide rail using rail dogs inserted into the perforated top, rather than attaching the guide rail to a fixed hinge. Reliable perpendicular cuts depend on the hole pattern, the dogs and the chosen rail being compatible. These details still need to be checked.

The current CAD assembly places the 800 mm rail along the short Y/depth direction, centred over X=0 and resting on the worktop top face. This is a neutral layout position, not the final rail-dog location or a reproduction of Festool’s swivel/support hardware.

For the Festool-style guide-rail profile, this measured cross-section is the dimensional reference used by the CAD component:

  • TSO Products — Guide Rail Extrusion Comparison Guide — measured cross-section dimensions for several commercial guide rails, including Festool and Makita. This is a dimensional reference, not an official manufacturer production drawing or tolerance specification.

The reusable GuideRail CAD component has a parameterised length. The Festool standalone result uses 1400 mm, the Makita reference result uses 1500 mm, and the first Simple MFT assembly uses 800 mm.

A possible low-cost guide rail is the XIUYI rail system sold in several lengths:

  • XIUYI circular-saw guide rail on Banggood

The listing advertises several lengths and compatibility with Makita/Festool-style systems. The actual fit with the saw and chosen rail dogs remains to be verified.

Fence / stop system

An additional idea is to build a sliding fence or stop using IKEA VIDGA curtain rail components.

VIDGA is interesting because it is a simple aluminium track system that can be cut to length and accepts sliding runners. The project should investigate whether that can be adapted into a lightweight fence or movable stop rather than using a more expensive woodworking-specific track system.

The following two references show possible flip-stop mechanisms:

These references are examples of a flip-stop mechanism. Using VIDGA as the track is still only an idea; stiffness, locking method and accuracy have not been verified.

Questions to work out

  • What overall worktop size is useful without making the setup cumbersome?
  • Is a ready-made perforated MDF top accurate enough for bench dogs and rail positioning?
  • What hole spacing does the Craftmaker top actually use, and is it accurate enough for rail dogs?
  • Which rail-dog/support arrangement should set the guide rail position for repeatable perpendicular cuts?
  • Can a VIDGA rail be turned into a sufficiently rigid and lockable fence/stop system?
  • What support, if any, is needed later? No box or base is part of the current design.
