HUB75 LED Matrix Display

● Active · 📐 Design · Started 2026-07 · Updated 2026-10-29

HUB75, Electronics, OpenSCAD, Woodworking, 3D Printing

This project is about building a display using HUB75 LED matrix modules.

The project collects design notes, references and possible solutions for the mechanical construction, electronics and software.
