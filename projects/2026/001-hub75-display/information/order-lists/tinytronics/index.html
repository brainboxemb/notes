The power-distribution items above correspond to the current power-distribution prototype concept.

The 2.54 mm auxiliary terminal is mechanically attractive because it fits standard 2.54 mm experiment-board spacing. It is a lower-current option than the 5.08 mm terminal, so it should only be used where the expected current remains within its 6 A rating.

Controller USB extension

The 50 cm panel-mount cable is a candidate for bringing the controller’s internal Micro-USB connection to the outside of the enclosure.

TinyTronics specifies the cable as shielded USB 2.0, with a Micro-USB male connector on the controller side and a panel-mount USB-B female connector on the outside. The published maximum current is 0.5 A.

For now this is a candidate part. The final enclosure should be tested with the HUB75 panels operating at realistic brightness to confirm that:

  • USB communication remains reliable next to the high-current LED wiring;
  • the 50 cm extension does not introduce communication problems;
  • 0.5 A is sufficient if the same USB connection is also expected to power the controller.

Service / reset button

A possible enclosure button is the TinyTronics AB6Y-M-BLACK:

  • TinyTronics — Black Push Button 16 mm - Reset

This is a momentary 16 mm push button: it returns to its original position after being pressed, so it is suitable as a reset or service input rather than as a latching power switch.

For now it is a candidate part. The exact software function and wiring still need to be decided.
