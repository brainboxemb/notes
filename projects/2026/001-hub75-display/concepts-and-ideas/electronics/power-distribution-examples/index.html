Power Distribution Examples

Examples that inspired the HUB75 power-distribution concept.

These are references, not the proposed design. Where a verified reference image is available, it is shown as a small thumbnail (maximum 300 px wide). Clicking an image or product name opens the original product page, and the image source is written out explicitly below the thumbnail.

Screw-terminal distribution

Evemodel PCB005 power distribution board
Useful reference for a central input feeding two long rows of screw-terminal outputs.
Image/source: RJ's Trains — same Evemodel PCB005 product — https://rjstrains.com/products/evemodel-pcb005-1x-power-distribution-board-3-inputs-2-x-10-outputs-for-dc-ac-voltage
WayinTop double-layer power distribution board
Reference for separate positive and negative rails with many repeated screw-terminal positions.
Image/source: Amazon product page for the WayinTop board — https://www.amazon.nl/dp/B093PWRJS9

Plug-in distribution

Building Block Robotics XT30 Power Distribution Board
One input feeding three compact, individually disconnectable XT30 outputs.
Image/source: Building Block Robotics — https://buildingblockrobotics.com/products/xt30-power-distribution-board
Eckstein Robotics XT30 6-port parallel power distribution board
One XT30 input feeding six parallel XT30 outputs in a compact PLA protective enclosure.
Image/source: Eckstein Robotics — https://eckstein-shop.de/xt30-6-port-parallel-power-distribution-board-pla-case

What is useful for our concept

The screw-terminal examples are closest to the current prototype idea: a central supply feeding repeated connection points.

The XT30 examples are mainly useful for the mechanical idea of a single distribution point with branches that can be disconnected individually.
