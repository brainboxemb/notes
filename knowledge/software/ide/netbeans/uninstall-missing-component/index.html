NetBeans uninstall: missing target component

Created: 2 Nov 2026

Problem

Uninstalling NetBeans 23 on Windows shows:

The specified target component - nb-all/23.0.0.240913.0 was not found in the registry.

Choosing Yes may display a successful completion, while the program remains installed. This is also reported in Apache NetBeans issue #8049.

The likely cause is missing information in the NetBeans installer’s own registry:

%USERPROFILE%\.nbi\registry.xml

This is not necessarily a problem with the Windows Registry.

Possible fix

A workaround reported in the GitHub issue:

  1. Close NetBeans and back up %USERPROFILE%\.nbi (including registry.xml).
  2. Rename C:\Program Files\NetBeans-23 to NetBeans-23.old.
  3. Download and reinstall the same NetBeans 23 version using the official installer.
  4. Open Programs and Features: press Win + R, type appwiz.cpl, and press Enter. In the list, select Apache NetBeans IDE 23 and click Uninstall. Alternatively, open Control Panel → Programs → Programs and Features.
  5. Verify that it is gone before deleting NetBeans-23.old. Remove NetBeans 25 separately; if necessary, repeat with its matching installer.

Do not delete project folders or your complete .nbi directory as a first step. If only a Windows uninstall entry remains, Microsoft’s Program Install and Uninstall troubleshooter may help.

Status: The error is confirmed, but this workaround has not yet been tested successfully on this PC.

Reference: Apache NetBeans #8049 — Unable to uninstall.
