NetBeans: selecting the Java version for Maven

Created: 2 Nov 2026

Problem

NetBeans runs with Java 21, but Maven builds use Java 8.

NetBeans can use separate Java versions for the IDE itself and for Maven. Changing the IDE’s netbeans_jdkhome setting does not automatically change Maven’s JDK.

Solution

Open Tools → Options → Java → Maven → Default JDK and select the JDK you want Maven to use.

In this case, Default JDK was still set to JDK 1.8, even though the IDE was running on Java 21. Selecting JDK 21 addresses that configuration mismatch.

To check, run a Maven build and look at the JAVA_HOME value shown in the NetBeans output. The IDE sets this value for its Maven command, so it does not necessarily come from the Windows PATH.

If the intended JDK is not listed, register it under Tools → Java Platforms.
