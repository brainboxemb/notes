Git Code Libraries

Useful OpenSCAD libraries and reusable code worth keeping as references.

BarsAndTubes

quirxi/BarsAndTubes

A small OpenSCAD library for common bar and tube profiles. It includes helpers for hexagonal, rectangular, square and round bars, rectangular/square/round tubes, angle iron and U profiles.

Useful when modelling constructions made from standard metal profiles without repeatedly rebuilding the profile geometry.

Round-Anything

Irev-Dev/Round-Anything

An OpenSCAD utility library focused on rounded geometry. Its core approach uses polygon points with a radius value at each point, making it easier to build parts with internal and external radii.

It is also interesting as a broader OpenSCAD design approach: build parts from 2D profiles and then extrude them, rather than treating rounding as an afterthought.

relativity.scad

davidson16807/relativity.scad

An OpenSCAD library for sizing, positioning and orienting objects relative to other geometry.

It provides replacement primitives and helpers for alignment, attachment points, repeated transforms and selective CSG operations. This can make larger assemblies easier to describe because parts can be positioned relative to their parent geometry instead of using many manually calculated translations.
