ModelRift OpenSCAD models

2026-10-30

ModelRift

Interesting OpenSCAD model site with interactive previews and parameter controls. Model pages expose the OpenSCAD source and, for AI-assisted models, can also show the prompt used to create the model.

This makes the site useful both as a collection of practical OpenSCAD examples and as a reference for how code-based CAD can be presented and customized in a browser.

Examples

  • Cable Conceal Box — published 24 March 2026. A customizable wall-mounted cable conceal box with configurable dimensions, cable-hole position, clearances and snap features.
  • Room interior layout via AI — published 5 July 2026. Uses OpenSCAD for an accurately dimensioned room and furniture layout rather than only an artistic visualization.
  • Neat clamshell box. Print-in-place, customizable — published 21 June 2026. A customizable print-in-place clamshell box with hinge, snap-fit closure and many exposed fit parameters.
  • Why we built ModelRift on OpenSCAD — published 4 February 2026. Explains why ModelRift chose OpenSCAD for AI-assisted CAD, including the small declarative language, easier sandboxing and fast rendering with the Manifold backend.

Worth investigating

The interactive customizer itself is interesting: parameters can be changed in the browser while the OpenSCAD model is redrawn. It is also useful to compare how ModelRift exposes source code, prompts and configurable parameters around the same model.
