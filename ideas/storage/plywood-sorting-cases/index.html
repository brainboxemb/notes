Plywood Sorting Cases

A portable plywood organiser case for screws, fasteners and other small parts. Plywood is practical for the larger panels, while 3D-printed parts can handle fittings and removable bins.

Promising design: Wood Sorting Case

Wood Sorting Case (Sortimo T-BOXX compatible) — Pakue on Printables

A useful starting point for a wooden sorting case. The Printables design includes an assembly-instructions PDF; its description mentions 12 mm wood pieces.

Important: the published case is intended for Sortimo T-BOXX-compatible inserts, not specifically for Gridfinity. Using Gridfinity bins would need a suitable internal baseplate and a check of the available dimensions.

Gridfinity discussion

Wanted — Plywood Case for Gridfinity boxes — r/gridfinity

A discussion about combining a plywood case with Gridfinity inserts, including examples of adapted wooden cases. The Printables design above is recommended in the comments.

A related but different approach is Eurobox Dividers, using an existing Eurobox with wooden panels and 3D-printed clips.

Points to explore

  • Whether the case should use Sortimo inserts or Gridfinity bins.
  • Internal dimensions and the 42 mm Gridfinity grid if using a Gridfinity baseplate.
  • Lid clearance and whether small parts stay inside the bins during transport.
  • How easily the case could be resized or built with ordinary woodworking tools.

These are references for a possible future build; no design has been selected yet.
