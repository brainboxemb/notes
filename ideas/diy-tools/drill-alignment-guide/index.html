Digital Drill Alignment Guide

Could a compact microcontroller board with a round display and a six-axis motion sensor provide visual feedback to help keep a handheld drill at the intended angle? This is an idea to explore, not a planned build.

Inspiration: Copilot Drilling

Copilot Drilling is a commercial drill-mounted alignment aid. A ring of coloured LEDs indicates how to correct the drill’s angle. The retrofit version fits to the rear of a drill using an adapter, and a zero function supports a chosen reference orientation.

The interesting part is the simple, immediately visible feedback during drilling, rather than showing an angle as a number.

For a visual explanation of aligning a drill with the surface of the workpiece, see this YouTube Short.

Another approach: laser circles

BullseyeBore Core takes a different approach to drill alignment: instead of a sensor and display, it projects laser circles onto the surface being drilled.

As the drill chuck rotates, one laser beam parallel to the drill bit traces a reference circle on the workpiece. A second beam, aimed at an angle, traces an alignment circle.

  • Drill square to the surface: the rings share the same centre (concentric).
  • Drill tilted: the alignment ring becomes offset and more elliptical relative to the reference ring.

Why two circles? The point is not to measure their diameter. It is easier to see whether the rings share one centre than to judge whether a single projected circle is slightly distorted.

Simple schematic of the alignment principle, not a drawing of the product.

This is a useful contrast to the ESP32 idea: the lasers compare the drill directly with the actual workpiece surface, even if that surface is sloping. They do not need an IMU or a separate sensor against the wall, but the drill must be turning for the rings to appear.

Concept

A small, removable electronic drill alignment guide fitted to the back of a cordless drill. A motion sensor measures the drill’s orientation, while a round screen shows an intuitive digital bubble or moving crosshair to help the user maintain a chosen drilling angle. A zero/calibration action could set a gravity-based reference angle; a 3D-printed mount would connect the device to the drill.

This is an initial design concept, not a tested solution. In particular, it remains to be explored how the reference angle, sensor-to-bit calibration and on-screen feedback would work in practice.

Display idea

Original UI concept illustration, not a screenshot or tested design.

A moving dot approaches the centre of a crosshair; the indicator changes from red to yellow to green as the drill approaches the chosen orientation. This is just one possible interface for the round display.

Possible hardware

The smaller Waveshare RP2350-Touch-LCD-1.46 is an interesting alternative to the larger ESP32-S3 board. Both use the same QMI8658 six-axis sensor (accelerometer and gyroscope), so the basic angle-measuring capability is comparable.

For a standalone graphical drill-angle indicator, the RP2350 should have ample capability: read the IMU and draw the crosshair, angle and zero-setting controls. It is smaller and less expensive. The ESP32-S3 becomes more interesting if a wireless second sensor is ever considered; RP2350 would require additional connectivity hardware for that approach.

References: RP2350 product and examples · ESP32-S3 product and documentation. A 3D-printed drill attachment and battery would still need to be designed for either board.

Practical drilling situations

The question is not whether the Waveshare has the same buttons as Copilot, but whether it can help maintain the intended drilling direction. With a six-axis accelerometer/gyroscope and a round display, the same basic principle appears feasible: set a reference and show the deviation while drilling.

Original schematic: each drilling direction is shown from two perpendicular viewpoints.

Drilling situationHow to set the referenceDIY guide with one motion sensor
Straight down into a flat board (90°)Use the vertical direction.Yes. Gravity provides a stable reference.
45° into a flat boardHold the drill at the desired 45° angle and facing the desired direction, then press zero.Yes in principle. The screen can show how the drill deviates from that starting position.
Straight into a vertical wall (90°)First set a direction perpendicular to the wall, then press zero.Yes in principle. Merely holding the drill horizontally is not enough; the wall-facing direction must be set first.
Angled hole into a wall or sloping boardSet the intended direction against a reference, then zero.Yes in principle, once that complete starting orientation has been established.

What does Copilot do differently? Copilot 2 already has a finished, calibrated sensor system, clear LED guidance, a rechargeable battery and a mounting system. Its five-second delayed zero lets the user put the back of the device against a workpiece to set a perpendicular reference. It does not automatically know the orientation of the surface.

A DIY version could follow this idea with a zero button and a moving dot on the screen. The accelerometer provides a stable gravity reference; the gyroscope tracks rotations away from the chosen orientation. Changes in direction that gravity cannot determine will slowly drift when calculated from the gyroscope, so the performance over a drilling operation needs testing. Copilot’s specific internal sensor is not published, and there is no evidence here that an additional sensor type is necessary to reproduce the basic functionality.

Related DIY references

No documented DIY drill alignment guide using a screen for live feedback has been found yet. The examples below cover parts of the idea, but not the same combination of drill mounting, IMU-based orientation and graphical feedback.

  • Build a Drill Position Indicator — Circuit Cellar (2021): the closest example found. A battery-powered drill alignment indicator built around an Arduino Nano, MPU-6050 IMU and LEDs, mounted in the drill’s support handle.
  • Planum — a Digital Spirit Level Tool (2025): a working digital level made with a Waveshare ESP32-S3 1.28-inch round display, six-axis IMU, battery and a 3D-printed enclosure. Not a drill guide, but a particularly relevant display/sensor example.
  • Humanix LA100 — GitHub: an open-source digital inclinometer using an Arduino Nano, MPU6050, OLED and laser. Another reference for sensor readout and calibration, not a drill attachment.

The drill-specific example uses LEDs; the display-based examples are general inclinometers or digital levels, not drill-mounted alternatives.
