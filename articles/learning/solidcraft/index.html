SolidCraft

Practical SolidCraft notes: sketch constraints, command references and experiments with a Python interface.

Working notes while learning SolidCraft, with an emphasis on the parts that are easy to miss when coming from script-based CAD.

Starting points

Sketching and constraints

Reference: SolidCraft — Sketching and constraints

The step-by-step example is a useful starting point:

  1. Start the sketch on the Top / XY plane.
  2. Draw the geometry — the example uses a rectangle and a circle.
  3. Dimension the geometry.
  4. Finish the sketch and use the resulting profile for a solid feature.

Step 3: positioning geometry with dimensions

Step 3 is especially important. It explains the part that is easy to overlook when trying to align an item precisely.

In the example, the rectangle is already fixed by the origin and its dimensions, while the circle can still move. The Dimension tool is then used to position the circle centre relative to the left and bottom sides of the rectangle.

So a dimension is not only a displayed measurement. It can also define where geometry is located. Once no degrees of freedom remain, the sketch becomes fully constrained.

This makes dimensions and constraints central when placing sketch geometry accurately instead of moving it until it only looks aligned.

Command reference

Reference: SolidCraft — Command reference

This is particularly useful when moving from the GUI towards automation. Command entries include the command name, available parameters and Automation details such as the command ID used by scripts, the CLI and MCP.

For example, creating a sketch is exposed as:

sketch.create

The command reference should therefore be one of the main references while experimenting with a higher-level programming interface.

Python interface experiment

Alongside learning SolidCraft itself, I am experimenting with a Python interface for SolidCraft:

  • GitHub repository
  • GitHub Pages

The goal is not necessarily to copy one existing CAD API, but to combine useful ideas from several approaches:

  • PythonSCAD
  • OpenSCAD / BOSL
  • CadQuery
  • MicroCAD
  • vcad

Useful API ideas and SolidCraft-specific discoveries can be collected here while the interface develops.
