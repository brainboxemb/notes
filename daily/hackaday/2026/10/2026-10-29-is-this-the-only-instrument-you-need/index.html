Is This The Only Instrument You Need?

2026-10-29

Hackaday — Is This The Only Instrument You Need?

Article published: 29 October 2026.

The article covers Pico.Lab, an open-source RP2350-based embedded multitool combining a four-channel oscilloscope, eight-channel logic analyser, GPIO, data logging, UART, SPI and I2C interfaces, plus an adjustable power supply.

The particularly interesting part is the GUI. Pico.Lab exposes a virtual network adapter over USB and serves its interface directly from the device, so the host only needs a web browser. The interface uses a window-based desktop model where individual instruments are opened as apps and can be arranged side by side. It also looks unusually polished for a microcontroller-hosted engineering tool, making the visual interaction model worth studying in its own right.

The project documentation describes a lightweight communication design using HTTP GET/POST together with Server-Sent Events (SSE), rather than requiring a dedicated desktop application.
