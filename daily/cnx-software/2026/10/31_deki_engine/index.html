CNX Software — Deki Engine: ESP32 gets a Unity-style editor and C++ 2D game engine

Article published: 25 October 2026. Added: 31 October 2026.

Deki Engine is an open-source, Apache-2.0-licensed C++ engine for interactive 2D graphics on embedded devices, with a visual editor for Windows and Linux. It targets ESP32 hardware including ESP32-S3-based boards, and can also run on a desktop through SDL3.

Note: The interesting part is the Unity-style workflow: assemble scenes with sprites, text, particles, tilemaps and animations in a visual editor, then build and flash them to an ESP32 board. Desktop execution via SDL3 makes it useful for developing graphics and interactions before moving to hardware.\n>\n> Related CNX Software reference: Tactility operating system for the ESP32 microcontroller family supports built-in and external applications.
